# HR Analytics (Power BI)

A Power BI dashboard on employee attendance, work-from-home and sick-leave patterns, April to June 2022.

![HR analytics dashboard](Screenshot%202024-01-26%20131245.png)

## What it does

- Headline cards for total working days, present %, work-from-home (WFH) % and sick-leave (SL) %.
- Per-employee table of present %, SL % and WFH %, plus a day-by-day attendance matrix (P, WFH, WO and other codes).
- Daily trend lines with trend markers for present %, WFH % and SL % across the quarter.
- Breakdown of each rate by weekday, to show which days people tend to work from home or take sick leave.
- Month filter (Apr, May, Jun 2022) that updates every visual.

## Built with

- Microsoft Power BI Desktop
- Power BI data modelling and DAX measures for the percentages

## Open it

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Windows).
2. Download `2nd_proj.pbix` from this repository.
3. Open it in Power BI Desktop and use the month filter to explore.

## Project status

Portfolio dashboard. Findings should be read in the context of the underlying attendance dataset and its assumptions.
